# Sample course: source and licence

| File | What it is |
|---|---|
| `vector_spaces.md` | Short introduction to vector spaces (6 sections, 4 equations, one exercise with solution), written for this project |
| `vector_spaces.pdf` | Born-digital PDF built from the Markdown with `scripts/make_sample_pdf.py` |

**Licence:** CC-BY-4.0, written for course2video by the project authors. No third-party
figures or text are included.

This is deliberately the *easy* case: a born-digital PDF with a text layer, simple
equations and no figures. It shows that the pipeline runs; it does not show that the
pipeline handles real archives (scans, complex formulas, figures). See `docs/limitations.md`.
